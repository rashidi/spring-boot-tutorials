= Spring Boot Tutorials
:site-url: https://rashidi.zin.my/spring-boot-tutorials/

Runnable Spring Boot sample applications and step-by-step guides covering Spring AI, Batch, Cloud, Data, GraphQL, Messaging, Modulith, Observability, Security, Test, and Web.

Read the full tutorials with search and navigation at **{site-url}[rashidi.zin.my/spring-boot-tutorials]**.

== Prerequisites

* **Java 25**
* **Docker** (required for Testcontainers-based modules)
* Gradle Wrapper (`./gradlew`) is included

== Module Categories

Tutorials are organized as `<category>/<tutorial>` Gradle submodules (e.g., `data/jpa-audit` maps to `:data:jpa-audit`).

== Running a Tutorial

Run tasks against any single module from the repository root:

[source,bash]
----
./gradlew :data:jpa-audit:test
----

== Local Development with Sparse Checkout

To check out only the tutorials you need alongside the shared Gradle configuration:

[source,bash]
----
git sparse-checkout init --cone
git sparse-checkout set gradle build-logic data/jpa-audit
./gradlew :data:jpa-audit:test
----

Reload the Gradle project in your IDE after updating the sparse-checkout selection. Root `settings.gradle.kts` configures only the checked-out modules.

== Build Conventions

* **Shared Logic**: The `build-logic` included build provides `zin.rashidi.tutorial-conventions`, pre-configuring Java 25, Spring Boot, dependency management, JUnit Platform, and JaCoCo.
* **Minimal Module Builds**: Each tutorial applies `zin.rashidi.tutorial-conventions` and declares only its own dependencies and custom configuration.
* **Auto-Discovery**: Root `settings.gradle.kts` automatically discovers `<category>/<tutorial>/build.gradle.kts`; new tutorials need no local Gradle wrapper or settings file.
