== Content & Deployment Pipeline

Tutorial documentation is authored alongside source code in module `README.adoc` files on `master` and published automatically to `gh-pages`:

[source,text]
----
master (<category>/<topic>/README.adoc)
   │
   ▼  sync-adoc.yml (on push to master)
antora (docs/modules/ROOT/pages/<category>-<topic>.adoc)
   │  • Strips CRLF line endings
   │  • Rewrites relative src/ links to master tree/blob URLs
   │  • Normalizes cross-module links to Antora xref: targets
   ▼
build-and-publish-antora.yml (on push to antora)
   │  • Builds site via Antora 3.1.14 + Lunr search index
   │  • Applies supplemental-ui/ Handlebars partials & CSS
   ▼
gh-pages (published site)
----

== Authoring & Maintenance Rules

* **Edit tutorial content on `master`:** Any manual edits made to synced files under `docs/modules/ROOT/pages/` on `antora` will be overwritten the next time `sync-adoc.yml` runs on `master`. Only `index.adoc` and `nav.adoc` are maintained directly on `antora`.
* **Add new tutorials to `nav.adoc`:** When a new `<category>/<topic>/README.adoc` is added on `master`, `sync-adoc.yml` copies it to `docs/modules/ROOT/pages/<category>-<topic>.adoc`. Add a corresponding `* xref:<category>-<topic>.adoc[Title]` entry under the matching category in `docs/modules/ROOT/nav.adoc`.
* **Keep `module-slug.js` aligned with new categories:** `supplemental-ui/helpers/module-slug.js` resolves each page's GitHub source directory and Gradle `:test` task from its filename prefix (`ai-`, `batch-`, `data-`, `messaging-`, `modulith-`, `security-`, `test-`, `web-`, with unprefixed pages resolving under `core/`). Update `module-slug.js` if introducing a new top-level module prefix.
* **Use Antora `xref:` links:** Cross-references between tutorials should use `xref:<category>-<topic>.adoc[]` so Antora validates links at build time.

== Local Build & Preview

Prerequisites: **Node.js 22+**

[source,bash]
----
# 1. Install Antora CLI, site generator, and Lunr search extension
npm install --no-save @antora/cli@3.1.14 @antora/site-generator@3.1.14 @antora/lunr-extension

# 2. Generate the static site into build/site/
DOCSEARCH_ENABLED=true DOCSEARCH_ENGINE=lunr npx antora antora-playbook.yml

# 3. Preview locally at http://localhost:8080
npx http-server build/site -p 8080
----
