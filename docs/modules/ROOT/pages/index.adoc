= Spring Boot: Samples & Tutorials
:nofooter:
:icons: font
:url-quickref: https://github.com/rashidi/spring-boot-tutorials

Runnable https://spring.io/projects/spring-boot[Spring Boot] sample applications and step-by-step guides covering Spring AI, Batch, Cloud, Data, GraphQL, Messaging, Modulith, Observability, Security, Test, and Web. Each tutorial includes runnable source code organized as `<category>/<tutorial>` Gradle submodules on {url-quickref}[GitHub].

== Motivation

While Spring Boot tutorials are widely available, it is challenging to find guides that stay up-to-date and include automated integration tests—backed by real databases and services via Testcontainers—to verify the implementation and ensure long-term stability.

== Commitment

Continual improvement is fundamental in software development. This repository is committed to adhering to best practices and keeping all dependencies current. The quality of these tutorials and the knowledge imparted is, and always will be, my primary goal.

With the help of https://github.com/dependabot[Dependabot], every tutorial is continuously updated to the latest dependencies, targeting Java https://adoptium.net/en-GB/temurin/releases/?version=25[Temurin 25] and the latest https://spring.io/projects/spring-boot[Spring Boot] release.
