## 2026-09-28 - [Spring Data REST Associations]\n**Learning:** In Spring Data REST modules, the framework serializes associations as HATEOAS links instead of inline objects, meaning `FetchType.LAZY` on `@ManyToOne` relationships is safe to use and will not cause `LazyInitializationException` errors during JSON serialization.\n**Action:** Use `FetchType.LAZY` for `@ManyToOne` associations in Spring Data REST to avoid unnecessary database queries and N+1 selects.
